Titanic EDA Project

About

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python.

Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn

Visualizations

1. Survival Count
2. Survival by Gender
3. Passenger Class Count
4. Survival Rate by Passenger Class
5. Survival by Age
6. Survival by Embarkation Port
